# Todo List

A simple, responsive task manager built with HTML, CSS, and vanilla JavaScript. Tasks are saved in the browser, so they are still there after you refresh or close the page.

**[Live Demo](https://mahdimohammadi7.github.io/todo-app/)**

## Features

- Add new tasks
- Mark tasks as done or not done
- Delete tasks
- See how many tasks are left
- Tasks are saved in the browser with `localStorage`
- Responsive layout that works on mobile and desktop

## Built With

- HTML5
- CSS3
- JavaScript (ES6+), no frameworks or libraries

## Getting Started

1. Clone the repository:
   bash
   git clone https://github.com/mahdimohammadi7/todo-app.git

2. Open the project folder.
3. Open `index.html` in your browser. No build step or installation is needed.
